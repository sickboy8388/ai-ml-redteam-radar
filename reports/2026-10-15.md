## Top 3 of the day

1. [Decepticon CVE-2026-61732: ChatML injection in agent web crawl](https://github.com/advisories/GHSA-g5f9-3xfg-p9mf) — GHSA (2026-09-24)
   Attacker places ChatML special-token literals on a web page; when a Decepticon agent
   crawls it, the model's tokenizer parses them as real special tokens, forging an
   operator-level turn. CVSS 10.0. Affects any BYOK agent using vLLM, Ollama, or LM Studio
   backends that don't strip these literals. vLLM declined to fix at inference layer.

2. [MCP SDK CVE-2026-104850: OAuth credential theft](https://github.com/advisories/GHSA-6qxp-vccf-f47h) — GHSA (2026-10-06)
   MCP TypeScript SDK let servers choose which authorization endpoint received client
   credentials. A malicious MCP server could steal refresh tokens and client secrets without
   user interaction. Fixed in SDK 1.31.0 / client 2.2.0. Rotate secrets if untrusted MCP
   servers were ever connected.

3. [Kairos: Transactional Security for LLM Agents](https://arxiv.org/abs/2610.18457) — arXiv (2026-10-13)
   Reference monitor at the agent's system boundary; treats tool calls, shell commands, and
   scripts as file/network operations. Defers ambiguous effects for a bounded oracle to
   decide. Reduces AgentDojo attack success 47.0%→2.7% with no utility loss. Directly
   applicable to hardening local agent setups.
