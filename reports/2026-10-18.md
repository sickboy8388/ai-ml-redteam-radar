## Top 3 of the day

1. [PackHallu: Package Hallucination Attacks via Rule Files](https://arxiv.org/abs/2610.09264) — arXiv (2026-10-07)
   Injecting prompts into AGENTS.md/.cursorrules files causes coding agents to replace
   legitimate dependencies with attacker-controlled packages. High ASR across LLMs and
   frameworks. Directly relevant to local agent setups using shared rule files.

2. [COPEX: 64.4% attack success across MCP layers](https://arxiv.org/abs/2610.04378) — arXiv (2026-10-03)
   First comprehensive MCP benchmark: 25 attack types, 9 models, 3,375 trials. Some attacks
   succeed outside the model's observation. Combined scanning cuts success by 49.6%.

3. [vLLM v0.32.0 security release](https://github.com/vllm-project/vllm/releases) — vLLM (2026-10-18)
   Three security fixes: SSRF in MiMoV2Omni (CVE-2026-73560), tokenizer max_token_id issue,
   P2P ZMQ socket exhaustion. Also restricts default CORS origins and limits JSON schema
   nesting depth. Upgrade recommended for self-hosted deployments.
