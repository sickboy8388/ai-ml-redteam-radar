## Top 3 of the day

1. [LMCache CVE-2026-105192 — pickle RCE in distributed inference cache](https://github.com/advisories/GHSA-w5f2-9q9c-ff4h) — GHSA (2026-10-16)
   Unauthenticated RCE via pickle deserialization on ZeroMQ socket (default port 5555) in
   LMCache ≤0.5.5, used by vLLM for distributed KV cache sharing. JFrog published a PoC.
   Official containers run as root. Fix: upgrade to 0.5.6.

2. [vLLM v0.32.0 security hardening](https://github.com/vllm-project/vllm/releases/tag/v0.32.0) — vllm-project (2026-10-18)
   Three GHSAs fixed (chat template DoS, tokenizer off-by-one, P2P socket exhaustion). CORS
   default changed from `*` to none. Untrusted images restricted to raster allowlist.
   Multimodal cache handles now HMAC-signed. Plus FP8/NVFP4 KV cache on more GPU generations.

3. [APEX: Chaining Skills to Hijack LLM Agents](https://arxiv.org/abs/2610.01564) — arXiv (2026-10-01)
   Adversarial skill chains propagate false user-approval records across chained skills;
   74.2% targeted-action success across 6 models (84.3% on GPT-5.4). Splitting the attack
   across skills is the key — same steps in one skill: 17.4%. Prompting defense cuts success
   to 59.1% but also halves benign task performance.
