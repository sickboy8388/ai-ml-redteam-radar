## Top 3 of the day

1. [PackHallu: Rule File Injection for Coding Agents](https://arxiv.org/abs/2610.09264) — arXiv (2026-10-07)
   Prompt injection hidden in community-shared rule files (.cursorrules, AGENTS.md) makes
   coding agents hallucinate and install attacker-controlled packages. Uses evolutionary
   refinement via agent trajectory feedback. Directly threatens anyone using AI coding
   assistants with downloaded config files.

2. [WebMirage: Adversarial Images Hijack Web Agents](https://arxiv.org/abs/2610.09240) — arXiv (2026-10-07)
   Localized visual perturbations make vision-language web agents select attacker-controlled
   elements and execute browser actions. 91.9% attack success across 4 agent configs and
   6 VLM backbones, vs 17.4% for strongest baseline. Effective against 3 agent-level defenses.

3. [vLLM CVE-2026-41523: Malicious Model → RCE](https://github.com/advisories/GHSA-q8gq-377p-jq3r) — GHSA (2026-06-14)
   Assert-only security check in activation-function loading bypassed when Python runs
   in optimized mode. Malicious HuggingFace model triggers arbitrary code execution during
   initialization. Fixed in 0.22.0. Exemplifies the model-as-attack-vector supply chain.
