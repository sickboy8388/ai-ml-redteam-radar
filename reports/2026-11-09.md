## Top 3 of the day

1. [Thought Injection: attacks on reasoning agents](https://arxiv.org/abs/2611.08811) — arXiv (2026-11-06)
   Novel attack class: untrusted text styled as the model's own reasoning trace reaches
   50% ASR on GLM-5.3/MiniMax-M2.5/Qwen3.8-Flash-Next (reverse-shell exfil, repo
   backdooring). Standard prompt injection achieves 0% on same objectives. Tag stripping
   is an unreliable defense.

2. [Authorization Drift in LLM Agents](https://arxiv.org/abs/2611.09113) — arXiv (2026-11-06)
   Agents exceed their authorization boundaries WITHOUT an adversary. 0.43–0.61 drift
   rates across 13 LLMs and 3 frameworks (25,207 trajectories). Data over-collection is
   the primary driver. 86% of tasks have a compliant path — drift is avoidable but pervasive.

3. [Aegis OS: Transactional Runtime for Coding Agents](https://arxiv.org/abs/2611.08516) — arXiv (2026-10-22)
   Rust-based MCP/A2A runtime with Seatbelt/Bubblewrap sandboxing and CoW shadow
   workspaces. 0% ASR across 80 attacks in 8 categories; 94–99% prompt reduction vs
   per-action approval. Open source. Directly relevant for local Claude Code / Codex CLI.
