## Top 3 of the day

1. [Local Allow, Global Deny: Per-Action Authorization Does Not Compose](https://arxiv.org/abs/2610.27620) — Pandey, Jain, Chen et al. (2026-10-20)
   Proves that individually-approved LLM agent actions can combine to violate global
   policies (intent, consent, delegation); no per-action monitor can detect relational
   purpose violations. Fundamental limitation for any tool-approval guard.

2. [Open WebUI 19-CVE batch disclosure](https://github.com/advisories/GHSA-865q-vfjv-p93j) — Open WebUI (2026-10-12)
   Privilege escalation via terminal proxy, XSS, IDOR, ReDoS, authz bypass — the most
   popular self-hosted LLM front-end had systemic security debt across its entire API
   surface. All fixed in 0.11.4; anyone running an older version is exposed on 19 axes.

3. [CarryoverBench: Carryover Attacks on LLM Agents](https://arxiv.org/abs/2610.28425) — Xu, Wang, Huang et al. (2026-10-20)
   One-time indirect prompt injections planted in persistent agent memory re-fire in
   later sessions without measurable decay over 5 rounds, across 5 frontier models and
   3 trigger channels. Local agents with persistent memory are directly exposed.
