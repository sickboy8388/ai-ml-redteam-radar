## Top 3 of the day

1. [ToFu: Exploiting and Fuzzing the LLM-Orchestrator-Tool Trust Boundary](https://arxiv.org/abs/2610.13651) — arXiv (2026-10-09)
   First systematic fuzzing of MCP server tool implementations. 273 servers / 3,405 tools
   tested; 253 verified semantic security bugs in 118 servers (43%). Tools frequently fail
   to enforce their documented input semantics, so LLM-generated arguments are wrongly
   trusted. Immediate relevance for anyone deploying MCP servers.

2. [Cross-session attacks via persistent artifacts in agent skill composition](https://arxiv.org/abs/2610.13227) — arXiv (2026-10-09)
   Skills leave behind files, configs, and cached data that later sessions trust. Three
   attack mechanisms (instruction propagation, data boundary violation, evidence poisoning)
   achieve 46.7–77.4% ASR across 7 models in Codex CLI, Gemini CLI, and Claude Code.
   SkillRelayGuard defense cuts ASR from 69.5% to 10.9%.

3. [Vulnerable models in the AI supply chain](https://arxiv.org/abs/2610.12893) — arXiv (2026-10-09)
   Empirical study of 16,977 known-vulnerable models on Hugging Face. 22.1% are actively
   referenced in 21,000+ code locations across 5,000+ repos. No evidence of provenance
   verification or model sanitization in any recurring usage pattern.
