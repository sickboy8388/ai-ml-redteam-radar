## Study picks

- AgentLens (2611.34380) — Graph-guided auditing found 44 confirmed vulnerabilities
  (12 CVEs) across 5 widely-used agent apps; 3.67x more than AgentFuzz. Practical
  pre-deployment security tool for anyone running LLM agents.
- Recovery Security Downgrade / ARGUS (2611.33605) — Novel attack class: induced failures
  cause agents to silently replan without security protections. Not injection — exploits
  the agent's own recovery logic. ARGUS framework prevents all observed events.
