## Top 3 of the day

1. [SkillPoison: Progressive Skill Poisoning via Successful Experiences](https://arxiv.org/abs/2610.07645) — arXiv (2026-10-06)
   Self-improving agents can be poisoned through valid, verified trajectories — no
   obviously malicious content needed. 95.71% attack success while all injected experiences
   remain task-correct. Bypasses both verification and lexical inspection systems.

2. [HarnessSecurity-Bench: Do Security Mechanisms Really Protect Coding Agent Harnesses?](https://arxiv.org/abs/2610.07639) — arXiv (2026-10-06)
   First systematic benchmark across 6 coding-agent harnesses (Claude Code, Codex CLI,
   Gemini CLI, gptme, Qwen Code, GitHub Copilot). Auto-approval raises attack success from
   29.2% to 95.6%. Half of security mechanisms require opt-in, leaving defaults vulnerable.

3. [vLLM CVE-2026-41523: Assert-Based Security Bypass](https://github.com/advisories/GHSA-q8gq-377p-jq3r) — GHSA (2026-06-14)
   Python `assert` used as sole security control for activation-function loading from
   HuggingFace model configs. Running `python -O` strips the check → arbitrary code
   execution via malicious model. Crosses inference-server and supply-chain attack surfaces.
