## Top 3 of the day

1. [Open WebUI: 15+ CVEs disclosed in a single batch](https://github.com/advisories/GHSA-x8qf-hm43-c9g2) — GHSA (2026-10-12)
   The most widely-used self-hosted LLM web UI had privilege escalation (terminal proxy →
   admin API), cross-origin session theft (path-traversal chat ID steals JWT), multiple XSS,
   DoS, and authz bypass issues. All fixed in 0.11.4. If you run Open WebUI, upgrade now.

2. [SEAL: Persistent tool poisoning across multi-round agent workflows](https://arxiv.org/abs/2610.25372) — arXiv (2026-10-18)
   Shows that single-round tool-poisoning evaluations dramatically overstate defenses.
   SEAL's universal prefix-eliciting triggers sustain attack effectiveness across realistic
   multi-round agent interactions. Directly relevant to anyone deploying LLM agents.

3. [IBM Langflow OSS: RCE via improper input validation](https://github.com/advisories/GHSA-wvwm-whv3-3f6j) — GHSA (2026-10-07)
   Remote authenticated attacker can execute arbitrary code in Langflow 1.0.0–1.12.2
   (CVSS3 8.8). Paired with message-ownership bypass (CVE-2026-107366, CVSS3 8.3), this
   makes any unpatched Langflow deployment a high-value target.
