1. [vLLM CVE-2026-114053: code injection via code_revision](https://github.com/advisories/GHSA-f623-hjm8-5wg5) — GHSA (2026-10-21)
   Critical 9.2: client-supplied `code_revision` forwarded to `AutoProcessor.from_pretrained`
   → arbitrary Python execution when `trust_remote_code` is enabled. Unauthenticated via
   `/tokenize`. Affects vLLM 0.7.3–0.30.x; fixed 0.31.0.

2. [Open WebUI session cookie hijack (CVE-2026-109292)](https://github.com/advisories/GHSA-crcq-c44m-c92x) — GHSA (2026-10-12)
   OAuth-mode connections forward the full browser cookie jar to destination servers. Operators
   of OpenAI-compatible connections, tool servers, or terminal servers can replay session
   cookies to hijack admin accounts. Fixed 0.11.4. Part of a 9-CVE disclosure batch.

3. [LMCache CVE-2026-105192: pickle RCE in vLLM cache layer](https://github.com/advisories/GHSA-w5f2-9q9c-ff4h) — GHSA (2026-10-16)
   Critical 9.8: ZeroMQ transport in LMCache's multiprocess mode deserializes pickle in
   incoming messages with no authentication. Official containers run as root. Fixed 0.5.6.
